# Bruin for Data Engineers: planning documents

This repository holds the planning documents for a paid, browser-delivered Bruin course and its hosted platform.

Start here: `Master_Execution_Guide.md`. It defines how every session runs: plan first and wait for approval, research gaps and record findings in `docs/knowledge/`, decision tiers (stop and ask for money, legal, security, third-party contact, destructive actions, contract changes), end-of-session handoff, and commit without pushing.

Read order:
1. `Curriculum_Planning_Prompt.md` (original requirements, highest authority)
2. `Master_Execution_Guide.md`
3. `Prerequisites_Checklist.md` (run its preflight, report missing items)
4. `Course_Curriculum_Outline.md` (v3.0), only the sections the phase needs
5. `Course_Build_Prompt_Guide.md` for course phases A to G
6. `Hosted_Platform_Build_Spec.md` for platform phases 0 to 2
7. `Curriculum_Review_Notes.md` for revision history

Once the build repositories exist, copy the CLAUDE.md templates from `Master_Execution_Guide.md` section 12 into each and fill the bracketed items. Keep each CLAUDE.md under about 200 lines.

Style: no emojis, no em dashes, no filler openers, plain and direct. Markdown for documents.
Never read or write secrets. Never push without explicit instruction.
